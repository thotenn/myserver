# Configuration Reference

> Complete reference for every YAML file MyServer reads, every supported widget
> type, the icon resolver, and every environment variable. All files live in
> `HOMEPAGE_CONFIG_DIR` (default `/app/config` in container, `./config` in
> the dev compose).

If a file is missing on first boot, it is auto-copied from the embedded
skeletons (`internal/config/skeleton/*.yaml`). Every YAML / CSS / JS change
is hot-reloaded by `fsnotify` — no restart needed.

## `settings.yaml`

```yaml
title: My Dashboard
favicon: https://example.com/favicon.ico
theme: dark                   # dark | light
color: zinc                   # 23 themes (see below)
language: en                  # en | es
headerStyle: clean            # underlined | boxed | clean | cleaned | magnified | caterwaul
target: _blank                # _blank | _self | _top
backgroundImage: wallpaper.jpg # local file (config/wallpaper.jpg) — or a full URL
hideVersion: true
cardBlur: true

# Per-group layout
layout:
  Applications:    { style: row, columns: 4 }
  Infrastructure:  { style: row, columns: 4 }
  "Mail & Storage": { style: row, columns: 4 }

# Legacy — `quicklaunch:` is no longer required. The unified search/
# QuickLaunch UI is rendered by the `search:` widget in widgets.yaml.
# Keeping the block here forces the bar to render even without a
# `search:` widget; the sub-fields are no-ops today.
quicklaunch:
  searchDescriptions: true
  hideInternetSearch: false
  hideVisitURL: false

# Scripts (opt-in; only consumed if HOMEPAGE_SCRIPTS_ENABLED=true)
scripts:
  scriptDirs:
    - /app/scripts
  maxTimeout: 3600
  defaultTimeout: 60
  maxConcurrent: 5
```

**Color themes**: `white, slate, gray, zinc, neutral, stone, red, orange,
amber, yellow, lime, green, emerald, teal, cyan, sky, blue, indigo, violet,
purple, fuchsia, pink, rose`.

### `backgroundImage`

Accepts either:

| Form | Example | Resolves to |
|---|---|---|
| Local file under `config/` | `wallpaper.jpg` | `/api/config/wallpaper.jpg?v=<hash>` |
| Local in a sub-directory | `wallpapers/mountains.webp` | `/api/config/wallpapers/mountains.webp?v=<hash>` |
| HTTP / HTTPS URL | `https://images.example.com/bg.png` | passthrough |
| Data URI | `data:image/svg+xml;base64,…` | passthrough |

Allowed local extensions: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`,
`.avif`, `.ico`, `.bmp`. The image is applied as a fixed, cover-sized,
centred background on `<body>` with no repeat. Pair with `cardBlur: true`
for readable cards on top of busy images.

> `settings.scripts.scriptDirs`, `maxTimeout`, `defaultTimeout`, and
> `maxConcurrent` are read **once** at process start. The watcher
> hot-reloads `scripts.yaml` entries but does not rebuild the script
> manager — changing these values requires a container restart.

> `layout.<group>.tab` is parsed today but `index.templ` does not invoke
> the `TabNavigation` component; groups render as flat `<h2>` sections.

## `services.yaml`

```yaml
- Applications:
    - Vikunja:
        icon: vikunja.png
        href: https://tickets.example.com
        description: Task management
        server: my-docker-host
        container: vikunja-abc123
        showStats: true
        ping: https://tickets.example.com
        siteMonitor: https://tickets.example.com
        statusStyle: dot          # dot | basic
        weight: 10
        tabindex: 1

    - WordPress:
        icon: wordpress.png
        href: https://blog.example.com
        description: Blog
        server: my-docker-host
        container: wordpress-xyz
        showStats: true

    - CBuilder Demos:
        icon: mdi-format-list-bulleted
        href: https://github.com/thotenn/cbuilder
        description: Apps generated by CBuilder
        widget:
          type: customapi
          url: http://10.0.0.1:3000/api/demos
          display: dynamic-list
          mappings:
            items: demos
            name: name
            label: status
            target: "{url}"

- Maintenance:
    - Regenerate Config:
        icon: mdi-cog-refresh
        description: Re-detect containers and regenerate services.yaml
        type: script
        script: deploy-config
        requireConfirm: true
```

### Field reference

| Field | Type | Purpose |
|---|---|---|
| `href` | string | Click target; the whole card is a stretched link. |
| `description` | string | Subtitle. |
| `icon` | string | `mdi:`, `mdi-`, `si:`, `si-`, bare name, or absolute URL — see [Icons](#icons). |
| `container` | string | Docker container name (for stats + status). |
| `server` | string | Key in `docker.yaml`. |
| `showStats` | bool | Show CPU/MEM/RX/TX row. Default true when `container` is set. |
| `ping` | string | Hostname for ICMP (UDP mode, no `CAP_NET_RAW`). |
| `siteMonitor` | string | URL for HTTP HEAD-with-GET-fallback. Must match the service's URL. |
| `statusStyle` | string | `dot` (coloured dot) or `basic`. |
| `widget` | object | Inline widget config — see [Service widgets](#service-widgets). |
| `script` | string | Script name → renders an "Execute" button instead of a link. |
| `requireConfirm` | bool | Demand confirmation before running the script. |
| `weight` | int | Sort order inside the group (lower first). |
| `tabindex` | int | Forward-compatibility field for tabbed layouts. |

## `bookmarks.yaml`

```yaml
- Developer:
    - GitHub: { abbr: GH, href: https://github.com }
    - "Stack Overflow": { abbr: SO, href: https://stackoverflow.com }
- Social:
    - Reddit: { abbr: RE, href: https://reddit.com }
```

If `icon` is omitted, the bookmark name is matched against a built-in list of
common services (GitHub, GitLab, AWS, Cloudflare, Vercel, Postman, Ngrok, …)
and auto-assigned a Simple-Icons icon.

## `docker.yaml`

```yaml
# Unix socket
my-docker-host:
  socket: /var/run/docker.sock
  swarm: false

# Remote TCP
remote:
  host: 127.0.0.1
  port: 2375

# Remote TLS
secure:
  host: 10.0.0.1
  port: 2376
  tls:
    ca:   /path/to/ca.pem
    cert: /path/to/cert.pem
    key:  /path/to/key.pem

# Podman rootless (local dev)
local:
  socket: /run/user/1000/podman/podman.sock
```

      HOME: /root

## Environment variables

| Variable | Default | Description |
|---|---|---|
| `HOMEPAGE_CONFIG_DIR` | `/app/config` | YAML directory. |
| `HOMEPAGE_ALLOWED_HOSTS` | localhost defaults | Allowed hosts (comma-separated). `*` = explicit wildcard. Unset = localhost only. |
| `HOMEPAGE_SCRIPTS_ENABLED` | `false` | Enable the scripts feature. |
| `HOMEPAGE_ALLOW_PRIVATE_HOSTS` | `true` | Allow proxy to reach RFC1918 IPs and loopback. |
| `HOMEPAGE_PROXY_DISABLE_IPV6` | `false` | Force IPv4 in the proxy. |
| `HOMEPAGE_ENABLE_HSTS` | `false` | Add `Strict-Transport-Security` (HTTPS-only). |
| `HOMEPAGE_TRUSTED_PROXIES` | `127.0.0.1/8,::1/128` | CIDRs trusted for `X-Forwarded-For` parsing. |
| `HOMEPAGE_VAR_*` | — | Custom values. Used as `{{HOMEPAGE_VAR_X}}` in YAML. |
| `HOMEPAGE_FILE_*` | — | File paths. `{{HOMEPAGE_FILE_X}}` is replaced with file contents. |
| `TZ` | — | Timezone (used by `datetime` and scripts). |
| `DEBUG` | `false` | `zap` development mode. |
| `PUID` / `PGID` | `1000` | Container user/group (entrypoint). |

## Variable substitution in YAML

```yaml
# services.yaml
- Applications:
    - Plex:
        widget:
          type: plex
          url: http://plex:32400
          key:    "{{HOMEPAGE_VAR_PLEX_TOKEN}}"      # env value
          apiKey: "{{HOMEPAGE_FILE_PLEX_KEY}}"       # file contents
```

```bash
export HOMEPAGE_VAR_PLEX_TOKEN=abc123
export HOMEPAGE_FILE_PLEX_KEY=/run/secrets/plex_key
```

> If the variable / file does not resolve, the placeholder is preserved
> literally (`{{HOMEPAGE_VAR_MISSING}}`) instead of being replaced with an
> empty string — the error surfaces in the rendered YAML.

## Info widgets

Configured in `widgets.yaml`. Each widget has an HTTP handler that returns
HTML (HTMX) or JSON (API) based on the `HX-Request` header.

### `search`

Unified search bar: web search on Enter + live QuickLaunch dropdown that
filters services and bookmarks as the user types (`↑`/`↓` to navigate,
`Enter` to follow the highlighted one or fall back to the web engine,
`Esc` to close).

```yaml
- search: { provider: google, target: _blank }     # google | duckduckgo | bing
```

### `datetime`

Date/time in the configured locale (`es-ES` or `en-US`), updated every
second.

```yaml
- datetime:
    text_size: xl
    format:
      dateStyle: long           # short | medium | long | full
      timeStyle: short
      hour12: false
```

### `greeting`

Time-of-day greeting (morning, afternoon, evening, night); i18n strings
injected via `data-*` attributes.

```yaml
- greeting: { text_size: lg }
```

### `openmeteo` / `weather`

Current weather from [api.open-meteo.com](https://open-meteo.com), no API
key required. Emoji + temperature.

```yaml
- openmeteo:
    label: London
    latitude: 51.5074
    longitude: -0.1278
    timezone: Etc/UTC
    units: metric
    cache: 5
```

Endpoint: `GET /api/widgets/openmeteo?latitude=…&longitude=…&label=…`.

### `resources`

Reads `/proc/stat`, `/proc/meminfo`, `/proc/uptime`,
`/sys/class/thermal/thermal_zone0/temp`, `syscall.Statfs` — no external
deps.

```yaml
- resources: { label: CPU,  cpu: true, cputemp: true, uptime: true }
- resources: { label: RAM,  memory: true }
- resources: { label: Disk, disk: /, expanded: true }
```

Bars recolor on thresholds:

| Metric | Green | Yellow | Red |
|---|---|---|---|
| CPU | < 60 % | 60–85 % | > 85 % |
| RAM / Disk | < 75 % | 75–90 % | > 90 % |
| Temp | < 60 °C | 60–80 °C | > 80 °C |

Endpoint: `GET /api/widgets/resources?cpu=true&cputemp=true&uptime=true&label=CPU`.

## Service widgets

Widgets declared under a service's `widget:` field render inside the card
via HTMX. 160+ widget types ship in the binary
(`internal/widgets/registry.go`).

### `customapi`

```yaml
widget:
  type: customapi
  url: http://10.0.0.1:3000/api/demos
  # …or read local JSON directly:
  # url: file://data/mis-datos.json
  method: GET                        # optional, defaults to GET
  headers:
    Authorization: Bearer xxx
  display: dynamic-list              # text | list | dynamic-list | graph | tile
  mappings:
    items: demos                     # path to the array
    name: name
    label: status
    target: "{url}"                  # template; {field} pulls from the item
```

Display modes:

- `text` — a single formatted value.
- `list` — flat key-value list.
- `dynamic-list` — scrollable list with badges and links.
- `graph` — sparkline (numeric data).
- `tile` — grid of metric tiles.

**`file://` scheme**: `url: file://data/x.json` resolves to
`$HOMEPAGE_CONFIG_DIR/data/x.json`. Absolute paths
(`file:///absolute/path.json`) also work. No SSRF check — it's not a network
request — and changes are hot-reloaded.

### Docker stats (automatic)

Any service with `server`, `container`, and `showStats: true` gets a
4-column row (CPU / MEM / RX / TX) wired to `/api/docker/stats` via HTMX.

```yaml
- Vikunja:
    server: my-docker-host
    container: vikunja-abc123
    showStats: true
```

### Registry widgets

For a registered type (sonarr, radarr, plex, pihole, …),
`GenericProxyHandler` queries the registry to build the upstream URL and
auth automatically — no manual configuration of the API path is needed.

For unregistered types, fall back to `customapi` with the full URL plus
`{{HOMEPAGE_VAR_KEY}}`.

The skill's appendix lists every registered widget type:
`.agents/skills/add-widget/SKILL.md`.

## Icons

`iconURL()` in `templates/icons.go` resolves the `icon` field.

| Input | Resolves to |
|---|---|
| `vikunja.png` | `https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/png/vikunja.png` |
| `vikunja.svg` | `…/svg/vikunja.svg` |
| `mdi-restart` | `https://cdn.jsdelivr.net/npm/@mdi/svg@latest/svg/restart.svg` |
| `mdi:restart` | same as above |
| `si:github` | `https://cdn.simpleicons.org/github` (colored) |
| `https://example.com/logo.png` | passthrough |

[`homarr-labs/dashboard-icons`](https://github.com/homarr-labs/dashboard-icons)
maintains >1500 icons for self-hosted services.
